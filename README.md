# dotfiles

Personal dotfiles: zsh, git, and macOS configuration. Pure system/shell config — nothing agent-related lives here.

Agent skills, global agent rules, hooks, and workflows moved to the dedicated
[agentic-tools](https://github.com/k4black/agentic-tools) repo (`~/Projects/personal/agentic-tools`),
which wires Claude Code, Codex CLI, OpenCode, Cursor, and Kilo Code with a single `./install.sh`.

## Layout

```
.
├── .aliases.sh
├── .functions.sh
├── .gitconfig
├── .macos.sh
└── .zshrc
```
